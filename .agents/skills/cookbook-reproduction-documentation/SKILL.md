## When to use
- Writing or updating reproduction guides and examples for the Cookbook.
- Verifying that users can reproduce model results from scratch according to documentation.

## When not to use
- For internal code refactoring or operator optimization without user-facing documentation.

## Inputs expected
- Completed model training/eval workflow, execution logs, and target Cookbook structure.

## Outputs required
- Cookbook reproduction document, verified entry links, sanitized logs, and replication checklist.
