## When to use
- Integrating a new model architecture into TurboPhysAI for training or acceleration.
- Establishing baseline training scripts and launch configurations.

## When not to use
- For single operator development or minor parameter tuning.

## Inputs expected
- Target model repository, reference training entry point, and delivery requirements.

## Outputs required
- Integrated model codebase, launch configuration, baseline run records, and task handover summary.
