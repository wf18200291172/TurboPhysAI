## When to use
- Implementing optimization groups (OptimizationGroup / Recipe) for specific model modules.
- Configuring replacement targets and conditional application rules.

## When not to use
- For raw operator implementation without optimization grouping.

## Inputs expected
- Target module structure, optimization recipe requirements, and replacement criteria.

## Outputs required
- Optimization group code, configuration files, generation records, and activation verification logs.
