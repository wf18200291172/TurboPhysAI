---

## When to use
- Adding new custom operators or modifying existing operator implementations and interfaces.
- Exposing C++/HIP operators to Python.

## When not to use
- For high-level model architecture integration without operator changes.

## Inputs expected
- Operator source code, binding requirements, and reference implementation.

## Outputs required
- Operator implementation, pybind exports, correctness test results, and build artifacts.
